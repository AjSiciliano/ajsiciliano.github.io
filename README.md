# ajsiciliano.github.io

Personal academic website of Andrew Jordan Siciliano.

- `index.html` — the whole site (one page).
- `assets/fonts/` — Computer Modern (CMU Serif), SIL Open Font License (see `OFL.txt`).
- `assets/figures/` — figures for the selected research.

To update publications or code, edit the `PUBLICATIONS` / `REPOSITORIES` text in the original
design file and re-export, or edit `index.html` directly.
